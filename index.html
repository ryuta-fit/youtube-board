youtube-board

youtube-board は、自分の YouTube チャンネルの数字（再生数・再生時間・視聴維持率・流入元など）を読み取り、自分用の制作ボードに表示するための個人用ツールです。

できること

  • YouTube Analytics API と YouTube Data API を使い、利用者本人のチャンネルの統計を読み取る
  • 読み取った数字を、利用者本人のパソコンに保存し、本人だけが見るボードに表示する

できないこと

  • 動画の投稿・削除・編集、チャンネル設定の変更（読み取り専用の権限しか求めません）

利用者

このツールは作成者本人が自分のチャンネルのために使うもので、一般には提供していません。
