プライバシーポリシー

最終更新日：2026年11月12日

youtube-board（以下「本ツール」）は、作成者本人が自分の YouTube チャンネルの数字を確認するための個人用ツールです。

取得する情報

利用者が Google アカウントで許可した場合に限り、次の読み取り専用の権限で、利用者本人のチャンネルの情報を取得します。

  • YouTube アナリティクスのレポート（再生数、再生時間、視聴維持率、流入元、登録者の増減など）
  • チャンネルと動画の基本情報（チャンネルID、動画のタイトル、公開日など）

利用目的

取得した情報は、利用者本人が自分のチャンネルの状況を確認するためだけに使います。

保存と共有

  • 取得した数字と認証情報は、利用者本人のパソコンに保存します。
  • 第三者への販売・提供・広告目的での利用は行いません。
  • 本ツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

許可の取り消しと削除

許可は Google アカウントの権限ページ からいつでも取り消せます。パソコンに保存したデータは、該当のファイルを削除することで消去できます。
